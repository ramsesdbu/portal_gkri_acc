Apostolic Community Church — Portal v3.1

Files included:
- index.html (public home with devotional examples)
- about.html
- contact.html
- login.html (member login)
- dashboard.html (member area)
- member-data.html (per-user member data form)
- prayer-list.html (per-user prayer & struggles table)
- job-board.html (per-user job postings)
- style.css
- script.js
- logo.png

Deploy to Netlify (quick):
1. Download and extract this ZIP.
2. Go to https://app.netlify.com/drop
3. Drag & drop the extracted folder contents into the page.
4. Wait for the deploy to finish and open the provided URL.
Notes:
- This demo uses localStorage in the browser. Each user’s data is stored locally and private to their browser.
- For production multi-device sync, integrate a backend (Firebase, Supabase, etc.).
